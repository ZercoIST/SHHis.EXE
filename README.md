# SHHis.EXE
设置快捷键，快速切换当前活动应用静音状态\
<br>
## 使用方法
1.从[Release](https://github.com/ZercoIST/SHHis.EXE/releases/)下载文件，解压后运行`SHHis.exe`\
2.右键右下角任务栏中的`SHHis`图标，设置快捷键、开机自启、屏幕提示\
3.使用设置的快捷键切换当前活动应用的静音状态\
<br>
本软件使用Gemini开发，基于AutoHotkey v2构建\
